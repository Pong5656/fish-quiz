# ติวความรู้ทางการประมง — งานเกษตรกำแพงแสน

เว็บติวสำหรับการแข่งขัน **ความรู้ทางการประมง** ระดับมัธยมปลาย
งานเกษตรกำแพงแสน คณะประมง มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน

ออกแบบสำหรับผู้ที่พื้นฐานชีววิทยาแน่นแต่ยังไม่เคยเรียนวิชาประมง
เนื้อหาจึงเน้นจุดที่ออกสอบบ่อย ตัวเลขที่ต้องจำ และคำตอบที่ต้องแยกให้ออก
ทุกหัวข้ออ้างอิงแหล่งที่ตรวจสอบย้อนกลับได้ ไม่มีเนื้อหาที่แต่งขึ้นเองโดยไม่มีที่มา

## โครงสร้างเว็บ

- **`/path`** — เส้นทางอ่าน 7 ด่าน ตั้งแต่เริ่มจนถึงวันสอบ
- **`/topics`** — เนื้อหาทั้ง 15 หมวด พร้อมจุดที่มักออกสอบและแหล่งอ้างอิง
- **`/read/[slug]`** — โหมดอ่านไล่ทีละช่วง พร้อมไฮไลต์คำสำคัญอัตโนมัติ
- **`/photos`** — คลังภาพถ่ายจริงจาก Wikimedia Commons พร้อมเครดิตครบ
- **`/quiz`** — ข้อสอบจำลอง 9 ชุด รวม 154 ข้อ
- **`/flashcards`** — บัตรคำท่องจำ
- **`/tricks`** — ทริกการแข่งขันแบบทีมละ 2 คน
- **`/competition`** — ข้อมูลการแข่งขัน กติกา และกำหนดการ
- **`/sources`** — ทะเบียนแหล่งอ้างอิงทั้งหมด
- **`/img-credits`** — ที่มาของภาพประกอบทั้งหมด

## ภาพประกอบ

ใช้ภาพสองประเภท

1. **ภาพถ่ายจริง 30 ภาพ** จาก [Wikimedia Commons](https://commons.wikimedia.org)
   คัดเฉพาะที่สัญญาอนุญาตเปิดให้ใช้ซ้ำได้ (CC BY, CC BY-SA, CC0, Public domain)
   ทุกภาพระบุผู้สร้าง สัญญาอนุญาต และลิงก์ต้นทางครบ
   เก็บข้อมูลไว้ใน `data/photos.json` และดึงมาด้วย `scripts/fetch-photos.cjs`
2. **แผนภาพวาดขึ้นเอง** สำหรับอธิบายโครงสร้างที่ภาพถ่ายแสดงไม่ชัด

## การพัฒนา

```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm run build    # สร้างเวอร์ชันใช้งานจริง
npm run start    # เปิดเซิร์ฟเวอร์เวอร์ชันใช้งานจริง
```

ดึงภาพเพิ่มจาก Commons (สคริปต์ข้ามภาพที่มีอยู่แล้ว):

```bash
node scripts/fetch-photos.cjs
```

## เหตุผลที่เนื้อหาบางส่วนเลือกใช้วิธีใดวิธีหนึ่ง

- ข้อสอบจำลองทั้งหมดจัดทำขึ้นใหม่ตามขอบเขตที่คณะประกาศ **ไม่ใช่ข้อสอบจริง**
  และไม่ใช่ข้อสอบที่รั่วไหลมาจากการแข่งขัน
- ภาพถ่ายจริงเป็นภาพของชนิดพันธุ์ห้องถิ่นหรือชนิดพันธุ์ที่พบในหลักสูตรไทยเป็นหลัก
  หากเป็นชนิดพันธุ์ต่างประเทศ จะระบุไว้ในคำบรรยายภาพ
- กำหนดการและกติกาของการแข่งขันให้ยึดประกาศจากเพจทางการเป็นหลัก

## แหล่งอ้างอิงหลัก

- หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาการประมง คณะประมง มหาวิทยาลัยเกษตรศาสตร์
- กรมประมง กระทรวงเกษตรและสหกรณ์
- เอกสารและประกาศของการแข่งขันความรู้ทางการประมง งานเกษตรกำแพงแสน

ดูรายการทั้งหมดได้ที่หน้า `/sources`
